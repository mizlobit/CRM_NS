# New Smart CRM — финальная mobile-first версия

Контрольное устройство: iPhone 13 Pro, 390 × 844 CSS px.

## Файлы для GitHub Pages

- `index.html`
- `styles.css`
- `script.js`
- `README.md`

## Реализовано

- Основной текст на мобильной версии — 17–18 px.
- Подписи — не меньше 15 px.
- Кнопки — не меньше 56–58 px.
- Кликабельные элементы — не меньше 44 × 44 px.
- Крупные иконки функций — 60–64 px.
- Карточки функций работают как аккордеоны.
- Строки бизнес-процесса также раскрываются по нажатию.
- AI-сообщения построены через flex и ограничены `max-width: 86%`.
- Добавлена поддержка iPhone Safe Area.
- Удалены фиксированные смещения и масштабирование через `scale/zoom`.
- Текст переносится и не обрезается.
- Добавлены адаптивные правила для 320, 350, 600, 768 и 1024 px.
- Добавлен FAQ со спойлерами.

## Публикация

1. Загрузите файлы в корень репозитория.
2. Откройте `Settings → Pages`.
3. Выберите `Deploy from a branch`.
4. Выберите `main` и `/(root)`.
5. Сохраните.

Форма заявки остаётся демонстрационной. Инструкция по подключению находится в `script.js`.
