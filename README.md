# New Smart CRM — mobile-first версия

Готовый статический сайт для GitHub Pages.

## Файлы

- `index.html`
- `styles.css`
- `script.js`
- `README.md`

## Что исправлено

- Полностью переработана мобильная версия.
- Исключён горизонтальный скролл и выезд текста за экран.
- Заголовки используют адаптивные размеры.
- Карточки автоматически перестраиваются под ширину устройства.
- Добавлено мобильное меню.
- CRM-демо адаптировано под телефон.
- Таблицы заменены на мобильные карточки.
- Улучшены отступы для экранов 320–430 px.
- Добавлена отдельная адаптация для экранов шириной менее 380 px.

## Размещение на GitHub Pages

1. Распакуйте архив.
2. Загрузите `index.html`, `styles.css`, `script.js` и `README.md` в корень репозитория.
3. Откройте `Settings → Pages`.
4. Выберите `Deploy from a branch`.
5. Укажите `main` и `/(root)`.
6. Нажмите `Save`.

## Важно

Форма заявки работает в демонстрационном режиме.
Инструкции по подключению формы находятся внизу файла `script.js`.
