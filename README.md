# New Smart CRM — сайт для GitHub Pages

Готовый статический сайт без сборщиков, npm и серверной установки.

## Состав архива

- `index.html` — структура сайта
- `styles.css` — дизайн и адаптивная версия
- `script.js` — интерактивное CRM-демо, анимации и форма
- `README.md` — инструкция

## Локальный запуск

Откройте файл `index.html` в браузере.

## Размещение на GitHub Pages

1. Создайте новый публичный репозиторий на GitHub.
2. Загрузите в корень репозитория:
   - `index.html`
   - `styles.css`
   - `script.js`
3. Откройте `Settings`.
4. Перейдите в раздел `Pages`.
5. В `Build and deployment` выберите `Deploy from a branch`.
6. Выберите ветку `main`, папку `/root`.
7. Нажмите `Save`.

Через несколько минут сайт будет опубликован.

## Перед публичным запуском

- Подключите форму заявки к Telegram, email или вашей CRM.
- Добавьте реальные контакты.
- При необходимости добавьте политику конфиденциальности.
- Замените демонстрационные кейсы на подтверждённые результаты после первых проектов.

## Форма заявки

Сейчас форма работает в демонстрационном режиме и не отправляет данные.
Инструкции по подключению находятся внизу файла `script.js`.
